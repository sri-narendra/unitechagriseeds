# Dealer App

WebView wrapper that loads the dealer portal from Vercel.

## Build

Open `androidapp/` in Android Studio → Sync → Run.

## Structure

```
androidapp/
├── MainActivity.kt      # WebView container
├── AndroidManifest.xml
├── activity_main.xml
├── strings.xml
├── colors.xml
├── themes.xml
├── build.gradle.kts
├── settings.gradle.kts
├── gradle.properties
└── dealer/              # This folder
```
